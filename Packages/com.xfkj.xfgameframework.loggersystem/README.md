# XFGameFramework.LoggerSystem

## 介绍
[XFGameFramework游戏框架](https://gitee.com/xianfengkeji/XFGameFramework.git)日志系统拓展包,通过该拓展包能够控制日志开关,监听日志事件!

## 安装

该拓展包基于XFGameFramework, 请确保已安装框架 [XFGameFramework](https://gitee.com/xianfengkeji/XFGameFramework)

点击 Window/XFKT/XFGameFramework/拓展包 如下图：

![](Documentation~/Textures/installer-1.png)

打开如下界面: 

![](Documentation~/Textures/installer-2.png)

选中 日志系统(LoggerSystem) 点击安装即可!
